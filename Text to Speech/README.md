# 🗣️ Text to Speech

## Project Overview

The **Text to Speech** web application allows users to convert written text into speech. Simply enter the text you want to hear, click the submit button, and the app will read it aloud for you.

🌐 **Live Demo**: [Text to Speech](https://atharvapatharkar.github.io/web-development-projects/Text%20to%20Speech/index.html)

---

## 💻 Tech Stack

- 📄 **HTML5**: Provides the structure of the page, including the input field and button.
- 🎨 **CSS3**: Styles the app to give it an attractive and easy-to-use interface.
- 🧑‍💻 **JavaScript**: Implements the functionality for converting text into speech using the browser's speech synthesis API.

---

## 🚀 How to Use

1️⃣ **Write** the text that you want to listen to in the provided text input field.  
2️⃣ **Click the "Submit" button**, and the text will be read aloud to you.

---

## 🔮 Future Enhancements

📌 Planned Features:  
- **Voice Selection**: Allow users to choose from multiple voices (male, female, different languages).  
- **Speed Control**: Let users control the speed or pitch of the speech output.  
- **Language Support**: Add support for multiple languages, allowing the user to hear text in their preferred language.
