This is a simple app to help you scale recipe ingredients based on the number of servings you need.

- 📄 **`index.html`**: HTML structure of the app.
- 🎨 **`style.css`**: CSS file for the app's design.

## 🌟 Features
1️⃣ **Ingredient Scaling** 🍴  
   - Automatically adjust ingredient quantities based on desired servings.

2️⃣ **User-Friendly Interface** 🖥️  
   - Clear input fields and results.

3️⃣ **Responsive Design** 📱  
   - Optimized for use on various devices.

---

## 🚀 How to Use
1️⃣ Clone or download the repository.  
2️⃣ Open `index.html` in your browser.  
3️⃣ Enter the original number of servings, desired servings, and ingredient amount.  
4️⃣ Click "Calculate" to see the adjusted ingredient amount.
