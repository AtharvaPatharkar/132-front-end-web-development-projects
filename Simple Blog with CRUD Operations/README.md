# 🧮 Welcome 🖐 to the Simple Blog with CRUD Operations

This project is a simple blog website that allows users to create, read, update, and delete posts. The posts are stored in the browser's local storage for persistence.

🌐 **Live Demo**: [Simple Blog with CRUD Operations](https://atharvapatharkar.github.io/web-development-projects/Simple%20Blog%20with%20CRUD%20Operations/index.html)

## 📂 Folder Structure

### 🔸 **Files Included**
- 📄 **`index.html`**: The main HTML file that contains the structure of the blog.
- 🎨 **`style.css`**: The CSS file that handles the layout and design of the blog.
- 🧑‍💻 **`script.js`**: The JavaScript file for handling CRUD operations and managing the blog data.
- 🧑‍💻 **`readme.md`**: Project documentation and instructions.

---

## 🌟 Features

### 1️⃣ **User-Friendly Interface** 🖥️  
   - 📝 Simple form to create a new post.
   - 🖋️ Clear display of existing posts.
   - 🚀 Button to update and delete posts.

---

### 2️⃣ **CRUD Operations** ⚙️  
   - 🔄 Create, Read, Update, and Delete posts.
   - ⏳ Data persists in the browser’s local storage.

---

### 3️⃣ **Responsive Design** 📱  
   - 🌐 Works well on desktop and mobile devices.
   - 📐 Clean and responsive user interface.

---

## 🚀 How to Use

🛠️ Follow these steps to use the Simple Blog with CRUD Operations:
1️⃣ Open **`index.html`** in your browser.
2️⃣ 📝 Enter a title and content for your post.
3️⃣ 🚀 Click **Create Post** to publish your post.
4️⃣ 🖱️ Use the **Edit** and **Delete** buttons to manage posts.
