# 🧮 Welcome 🖐 to the Trivia Quiz Game

Test your knowledge with this fun trivia quiz game! It fetches random questions from the Open Trivia DB API, and you can answer them to accumulate your score!

🌐 **Live Demo**: [Rivia Quiz Game](https://atharvapatharkar.github.io/web-development-projects/Rivia%20Quiz%20Game/index.html)

---

## 📂 Folder Structure

### 🔸 **Files Included**
- 📄 **`index.html`**: Main HTML structure of the Trivia Quiz Game.
- 🎨 **`style.css`**: Styling for the game, including modern design, multi-color background, and buttons.
- 🧑‍💻 **`script.js`**: JavaScript code that handles the logic for fetching trivia questions and checking answers.
- 📄 **`readme.md`**: Documentation for the project.

---

## 🌟 Features

### 1️⃣ **Random Trivia Questions** 🖥️  
   - Fetches trivia questions from the Open Trivia DB API.

### 2️⃣ **Answer Options** ⚙️  
   - Choose from multiple options to answer the question.
   - Your score increases with correct answers.

### 3️⃣ **Responsive Design** 📱  
   - Beautiful design with 3D effects and a multi-color background.
   - Fully responsive to work across devices.

---

## 🚀 How to Use

🛠️ Follow these steps to use the Trivia Quiz Game:
1️⃣ Open **`index.html`** in your browser.
2️⃣ Click on one of the answer buttons to answer the question.
3️⃣ After answering, click the **"Next Question"** button to move to the next question.
4️⃣ Continue answering questions and increase your score.
