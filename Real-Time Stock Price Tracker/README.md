# 🧮 Welcome 🖐 to the Real-Time Stock Price Tracker

This project allows you to track real-time stock prices using an API. The user can input a stock symbol and fetch the latest stock price in Indian Rupees (INR).

🌐 **Live Demo**: [Real-Time Stock Price Tracker](https://atharvapatharkar.github.io/web-development-projects/Real-Time%20Stock%20Price%20Tracker/index.html)

## 📂 Folder Structure

### 🔸 **Files Included**
- 📄 **`index.html`**: The main HTML file that sets up the layout and user interface.
- 🎨 **`style.css`**: The CSS file used for styling the page and elements.
- 🧑‍💻 **`script.js`**: The JavaScript file responsible for fetching and displaying stock prices using an API.
- 🧑‍💻 **`readme.md`**: Documentation for the project.

## 🌟 Features

### 1️⃣ **User-Friendly Interface** 🖥️  
   - 📝 Input field for stock symbol.
   - 🖋️ Clear display of real-time stock prices in INR.

---

### 2️⃣ **Real-Time Stock Price Updates** ⚙️  
   - 🔄 Fetches the latest stock price data.
   - ⏳ Updates every 5 minutes for fresh data.

---

### 3️⃣ **Responsive Design** 📱  
   - 🌐 Fully responsive layout for different devices.
   - 📐 Clean and visually appealing design.

## 🚀 How to Use

🛠️ Follow these steps to use the Real-Time Stock Price Tracker:
1️⃣ Open **`index.html`** in your browser.
2️⃣ Enter the stock symbol (e.g., AAPL for Apple).
3️⃣ Click **Get Stock Price**.
4️⃣ The current stock price in INR will be displayed.
