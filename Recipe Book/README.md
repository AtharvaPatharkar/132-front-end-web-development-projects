# 📖 Welcome 🖐 to the Recipe Book

Create and manage your personal collection of recipes with this interactive web app! Add, edit, and delete recipes effortlessly while your data is saved locally on your browser using local storage.

🌐 **Live Demo**: [Recipe Book](https://atharvapatharkar.github.io/web-development-projects/Recipe%20Book/index.html)

## 📂 Folder Structure

### 🔸 **Files Included**
- 📄 **`index.html`**: The main HTML file that structures the web page.  
- 🎨 **`style.css`**: CSS file for styling the recipe book interface.  
- 🧑‍💻 **`script.js`**: JavaScript file for managing recipes and local storage operations.  
- 📄 **`readme.md`**: Documentation for the project.  

---

## 🌟 Features

### 1️⃣ **Recipe Management** 🥘  
   - 📝 Add new recipes with titles, ingredients, and instructions.  
   - 🖋️ Edit existing recipes to update details.  
   - 🗑️ Delete recipes when they are no longer needed.  

---

### 2️⃣ **Dynamic Interface** ⚙️  
   - 🔄 Recipes dynamically displayed using JavaScript.  
   - ⏳ Instant updates without page refresh.  

---

### 3️⃣ **Persistent Storage** 💾  
   - 🌐 Uses local storage to save recipes.  
   - 🕒 Recipes remain available even after closing the browser.  

---

## 🚀 How to Use

🛠️ Follow these steps to use the **Recipe Book**:  
1️⃣ Open **`index.html`** in a browser.  
2️⃣ 🖱️ Add a new recipe by filling in the form and clicking **Add Recipe**.  
3️⃣ 🖋️ Edit or delete any recipe using the action buttons displayed with each entry.  
4️⃣ ✅ View and manage your recipes seamlessly across browser sessions.

- 🎨 **CSS3**: For styling and improving the visual design.

- 💾 **Local Storage**: For saving recipes persistently on the user's browser.
