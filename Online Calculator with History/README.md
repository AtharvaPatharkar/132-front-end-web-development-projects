---

## 🌟 Features

1️⃣ **Basic Arithmetic Operations**  
   - Supports addition, subtraction, multiplication, and division.

2️⃣ **History of Calculations**  
   - Displays a list of previous calculations and results.

3️⃣ **User-Friendly Interface**  
   - A clean and easy-to-use calculator interface with a history panel.

---

## 🚀 How to Use

1️⃣ Open **`index.html`** in your browser.  
2️⃣ Use the buttons to enter numbers and operators.  
3️⃣ Press **`=`** to get the result, and see it appear in the history below.  
4️⃣ **C** clears the current display.
