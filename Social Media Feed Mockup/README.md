# 🧮 Welcome 🖐 to the Social Media Feed Mockup

This is a mockup of a social media feed where users can scroll through posts, like, and comment. It is designed to mimic the core functionalities of a social media platform in a simplified form.

## 📂 Folder Structure

### 🔸 **Files Included**
- 📄 **`index.html`**: The main HTML file responsible for the structure of the feed.
- 🎨 **`style.css`**: The CSS file to style the layout and design.
- 🧑‍💻 **`script.js`**: The JavaScript file handling the functionality of liking and commenting on posts.
- 📄 **`readme.md`**: This readme file.

---

## 🌟 Features

1️⃣ **Post Content**  
   - Users can see posts with images, text, and their respective actions.

2️⃣ **Like and Comment**  
   - Users can like a post and toggle a comment box for adding comments.

3️⃣ **Modern Design**  
   - The feed is styled with vibrant colors and modern web design techniques.
